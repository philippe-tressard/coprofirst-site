Le logiciel de copropriété que vous pouvez lire.

Affaires, documents, carnet d'entretien, badges, vie entre voisins. Hébergé par votre résidence, sur votre serveur — vos données ne partent nulle part.

Explorer le dépôt Installer en trois étapes
~/residence 
$ git clone https://github.com/philippe-tressard/coprofirst.git
$ cd coprofirst
$ cp .env.example .env   # renseigner SECRET_KEY et ORIGIN
$ docker compose up --build -d
# → http://localhost

installer

En ligne en trois étapes

  1. Cloner le dépôt

    Sur n'importe quelle machine avec Docker : un Raspberry Pi suffit.

  2. Renseigner .env

    Une clé secrète, l'adresse du site, et c'est tout pour démarrer.

  3. Lancer

    docker compose up -d, puis le nom et le logo de la résidence se règlent dans l'administration.
