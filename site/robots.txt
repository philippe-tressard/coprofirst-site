# coprofirst.fr présente un logiciel libre : tout le site est ouvert, aux moteurs
# de recherche comme aux robots des assistants IA (indexation, réponses, et
# entraînement). Les groupes nommés ci-dessous ne restreignent rien : ils disent
# à chaque robot, par son nom, qu'il est le bienvenu. Chaque nom vient de la page
# officielle de son éditeur (relevé du 15/10/2026) ; un robot absent de la liste
# relève du groupe « * », tout aussi ouvert.
#
# Content-Signal : la préférence d'usage proposée par Cloudflare
# (contentsignals.org). Un robot qui trouve son nom dans un groupe ignore le groupe
# « * » : la ligne est donc répétée dans chaque groupe.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Allow: /
